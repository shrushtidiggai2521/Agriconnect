# AgriConnect — Frontend

Farmer-to-consumer marketplace frontend. React 19 + Vite + Tailwind CSS.

## Setup
```
npm install
npm run dev
```

Backend is expected at `http://localhost:8080/api` (Spring Boot). Configure in `src/utils/constants.js`.
